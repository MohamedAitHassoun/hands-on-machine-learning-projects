# **Hands-On Machine Learning Projects** 🚀

This repository contains three hands-on machine learning projects from the book **"Machine Learning for Beginners: A Step-by-Step Guide"**.

## **📂 Repository Contents**

✅ **House Price Prediction** (`house_price_prediction.ipynb`) *(Uses built-in dataset, no CSV required)*  
✅ **Spam Email Detection** (`spam_email_detection.ipynb`) *(Dataset included: `spam_emails.csv`)*  
✅ **Customer Segmentation** (`customer_segmentation.ipynb`) *(Dataset included: `Mall_Customers.csv`)*

---

## **⚙️ Setup Instructions**

Follow these steps to set up and run the projects on your machine.

### **1️⃣ Clone the Repository**

Open your terminal or command prompt and run:

```bash
git clone https://github.com/MohamedAitHassoun/hands-on-machine-learning-projects.git
cd hands-on-machine-learning-projects
```

### **2️⃣ Create a Virtual Environment (Recommended)**

To keep dependencies organized, it's best to create a virtual environment.

On Windows:
```bash
# Create virtual environment
python -m venv mlenv
```

On macOS/Linux:
```bash
# Create virtual environment
python -m venv mlenv
```
### 3️⃣ Install Required Libraries 

Once inside the virtual environment, install the necessary dependencies using:
```bash
pip install -r requirements.txt
```

### **4️⃣ Launch Jupyter Notebook**
Start Jupyter Notebook to explore and run the projects:
```bash
jupyter notebook
```
This will open a web browser where you can navigate to the .ipynb files and execute the code.

## **📊 Datasets**
* **House Price Prediction:** *No dataset file is needed; it uses a built-in dataset from a library.*
* **Spam Email Detection:** *Dataset file:* `spam_emails.csv` *(included in the repository)*
* **Customer Segmentation:** *Dataset file:* `Mall_Customers.csv` *(included in the repository)*

## **Project Details**

Each project contains detailed explanations, code implementation, and visualizations to help you understand the concepts and the results.

1. **House Price Prediction**
   - This project predicts house prices based on different features such as square footage, number of bedrooms, and other attributes.
   - It uses a built-in dataset from scikit-learn's `fetch_california_housing` function.

2. **Spam Email Detection**
   - The Spam Email Detection project uses text data to classify emails as spam or not spam.
   - The dataset (`spam_emails.csv`) includes emails with labels indicating whether they are spam or not.
   - We apply text processing and machine learning algorithms to perform the classification.

3. **Customer Segmentation**
   - This project uses customer data to segment them into different groups based on their characteristics (age, spending score, etc.).
   - The dataset (`Mall_Customers.csv`) is used to cluster customers using K-Means clustering.
