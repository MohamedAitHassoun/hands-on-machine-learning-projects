# **Hands-On Machine Learning Projects** 🚀  

This repository contains three hands-on machine learning projects from the book **"Machine Learning for Beginners: A Step-by-Step Guide"**.  

## **📂 Repository Contents**  

✅ **House Price Prediction** (`house_price_prediction.ipynb`) *(Uses built-in dataset, no CSV required)*  
✅ **Spam Email Detection** (`spam_email_detection.ipynb`) *(Dataset included: `spam_emails.csv`)*  
✅ **Customer Segmentation** (`customer_segmentation.ipynb`) *(Dataset included: `Mall_Customers.csv`)*
